# @ui/ui-lib React Component Library — Implementation Plan (Phase 1–4)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Scaffold `@ui/ui-lib` — a React 18 + TypeScript + Tailwind + shadcn/ui component library with a design-token system, a Button component, and a tsup build pipeline that outputs ESM + CJS + types + CSS ready for local `file:` installation.

**Architecture:** Design tokens live in `src/tokens/tokens.ts` as the single source of truth; a generate script writes them out as CSS variables to `src/styles/globals.css`; Tailwind reads them back via `var()` in `tailwind.config.ts`. Components use only semantic Tailwind classes (never arbitrary values). Build produces `dist/` via tsup (JS) + Tailwind CLI (CSS); distribution is via `npm pack` → `.tgz` installed with `file:` in consumer projects.

**Tech Stack:** pnpm, React 18, TypeScript 5 (strict), Tailwind CSS 3, shadcn/ui (manual components.json), CVA, clsx + tailwind-merge, tsup, Vitest + React Testing Library, tsx (script runner)

**Spec:** `readme.md` (project root)

## Global Constraints

- Package manager: `pnpm` (not npm/yarn)
- Package scope/name: `@ui/ui-lib`
- Node ≥ 18
- React/React-DOM declared as `peerDependencies` (>=18), never bundled
- All components use only semantic Tailwind class names (`bg-primary`, `rounded-md`, `p-md`) — **never** arbitrary values like `bg-[#fff]` or `p-[13px]`
- Any new design value (color, spacing, radius) goes into `src/tokens/tokens.ts` first, then a re-run of `pnpm tokens:generate`, then into the component
- Commit after each task completes
- Working directory for all commands: project root (`/home/duongpm3/projects/Frontend/ui-lib`)

```tsx
import * as React from 'react'
import { cva, type VariantProps } from 'class-variance-authority'
import { cn } from '../../lib/utils'

export const buttonVariants = cva(
  'inline-flex items-center justify-center rounded-md text-sm font-medium transition-colors focus-visible:outline-none focus-visible:ring-2 focus-visible:ring-ring focus-visible:ring-offset-2 disabled:pointer-events-none disabled:opacity-50',
  {
    variants: {
      variant: {
        default: 'bg-primary text-primary-foreground hover:bg-primary/90',
        outline: 'border border-input bg-background hover:bg-accent hover:text-accent-foreground',
        ghost: 'hover:bg-accent hover:text-accent-foreground',
      },
      size: {
        default: 'h-10 px-md py-sm',
        sm: 'h-9 px-sm',
        lg: 'h-11 px-lg',
      },
    },
    defaultVariants: {
      variant: 'default',
      size: 'default',
    },
  }
)

export interface ButtonProps
  extends React.ButtonHTMLAttributes<HTMLButtonElement>,
    VariantProps<typeof buttonVariants> {}

export const Button = React.forwardRef<HTMLButtonElement, ButtonProps>(
  ({ className, variant, size, ...props }, ref) => (
    <button
      ref={ref}
      className={cn(buttonVariants({ variant, size, className }))}
      {...props}
    />
  )
)
Button.displayName = 'Button'
```
